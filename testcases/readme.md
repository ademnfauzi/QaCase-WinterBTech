Alasan saya memilih Playwright adalah karena cukup reliable untuk aplikasi web modern, memiliki auto-waiting sehingga mengurangi flaky test, mendukung cross-browser dan parallel execution, serta mempunyai debugging dan reporting yang lengkap. Selain itu, support TypeScript dan Page Object Model membuat framework lebih mudah dikembangkan dan di-maintain.

Sedangkan untuk native mobile nantinya saya berencana menggunakan WebdriverIO yang terintegrasi dengan Appium karena lebih sesuai untuk berinteraksi dengan native Android dan iOS elements serta mobile gestures. Keduanya juga mendukung TypeScript, sehingga kami bisa menggunakan bahasa dan konsep framework yang konsisten antara web dan mobile.
